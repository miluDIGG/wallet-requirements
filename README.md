# Krav för det svenska plånbokssystemet

Detta kodförråd innehåller krav och kravunderlag för det svenska plånbokssystemet inom European Digital Identity Wallet (EUDI Wallet).

Dokumentationen förvaltas öppet i GitHub och migreras successivt från tidigare dokumentation i Confluence.

## Innehåll

- [Källor för krav](./a-kallor-for-krav/README.md)

Fler kravområden och underlag kommer att läggas till successivt.

## Syfte

Syftet med kodförrådet är att:

- samla krav och kravkällor på en gemensam plats
- möjliggöra versionshantering och spårbarhet
- göra förändringar granskningsbara
- möjliggöra samarbete genom GitHub Issues och Pull Requests

## Status

Projektet är under uppbyggnad och innehållet migreras successivt från Confluence.

## Förvaltning

Kodförrådet förvaltas av Myndigheten för digital förvaltning, Digg.

För frågor och ändringsförslag, använd i första hand GitHub Issues i detta kodförråd.
