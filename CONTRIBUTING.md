# Bidra till wallet-requirements

Tack för att du vill bidra till innehållet i detta kodförråd.

## Föreslå ändringar

Ändringar föreslås i första hand genom en Pull Request.

För mindre frågor, fel eller förbättringsförslag kan ett GitHub Issue skapas.

## Arbetsflöde

1. Skapa en egen branch från `main`.
2. Gör ändringen.
3. Kontrollera att Markdown-filerna renderas korrekt.
4. Skapa en Pull Request mot `main`.
5. Beskriv vad som har ändrats och varför.

## Krav på ändringar

Ändringar bör:

- vara tydligt avgränsade
- ange källa när krav eller kravunderlag ändras
- bevara spårbarhet till relevanta källor
- använda Markdown
- inte innehålla känslig information eller sekretessbelagt material

## Migrerat innehåll

Delar av dokumentationen migreras från Confluence.

Vid ändringar i migrerat innehåll bör det framgå om ändringen:

- endast är en teknisk konvertering
- rättar ett fel från migreringen
- innebär en faktisk förändring av innehållet
